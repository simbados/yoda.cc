Supported lock files

depsview reads npm lock files (package-lock.json, pnpm-lock.yaml, yarn.lock, bun.lock), Python manifests (requirements.txt, pyproject.toml, setup.cfg, Pipfile), Go modules (go.mod, go.sum), and Rust crates (Cargo.lock, Cargo.toml) straight from any public GitHub repository.

How it works

Polyglot repos (e.g. both package.json and go.mod) are resolved per ecosystem and rendered as separate sections, sorted independently.

"Paste file contents" analyses one pasted lockfile/manifest at a time for the selected ecosystem — the exact format is auto-detected from the content. A pasted requirements.txt that uses -r other.txt includes cannot resolve those includes (there is no repository to fetch them from); paste each file's contents together instead, or use GitHub URL mode.

npm, Go, and Rust packages from private registries are automatically skipped — the count of excluded entries is shown in the results. Python PEP 508 URL requirements (pkg @ https://…) are silently skipped.

Supply chain scores require a Socket.dev API key and org slug (enter above to add a Supply Chain column). Python download statistics (Downloads/mo column) are fetched via the same proxy Worker at socket-proxy.yoda.cc — enable with the checkbox above.
