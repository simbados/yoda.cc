Brewview

Analyse Homebrew formula dependencies.

All processing happens in your browser. Data is fetched directly from formulae.brew.sh — no data is sent to any other server.

GitHub authentication optional

Saved in your browser's local storage — readable by any JavaScript on this page. Uncheck and submit to remove.

60 req/hr without a token · 5 000 req/hr with one · used only for "Updated" date lookups · token sent only to api.github.com

What brewview does

brewview is a browser-based macOS Homebrew dependency tree viewer: paste any formula or cask and it resolves the full transitive dependency graph, pinned versions, and yearly install counts from formulae.brew.sh, with last-updated dates looked up via the GitHub API.

Install counts are sourced from the Homebrew analytics API and reflect the number of installs over the past 365 days across all versions of the formula.
